Déclaration d'accessibilité

Notre engagement

Terreur Productions s'engage à rendre son site web accessible à tous les utilisateurs, y compris les personnes en situation de handicap, conformément aux normes WCAG 2.1 niveau AA.

Nous travaillons continuellement à améliorer l'expérience utilisateur pour tous et à mettre en œuvre les meilleures pratiques en matière d'accessibilité web.

Mesures prises

Pour assurer l'accessibilité de notre site, nous avons mis en place les mesures suivantes :

  • Structure sémantique HTML5 pour une meilleure compréhension par les technologies d'assistance
  • Navigation au clavier complète et visible
  • Contraste de couleurs suffisant pour une meilleure lisibilité
  • Textes alternatifs pour toutes les images
  • Sous-titres pour les contenus vidéo
  • Conception responsive pour s'adapter à tous les appareils
  • Liens d'évitement pour faciliter la navigation
  • Utilisation appropriée des attributs ARIA

Compatibilité avec les technologies d'assistance

Notre site est conçu pour être compatible avec les technologies d'assistance suivantes :

  • Lecteurs d'écran (JAWS, NVDA, VoiceOver, TalkBack)
  • Logiciels de grossissement
  • Logiciels de reconnaissance vocale
  • Claviers adaptés

Navigateurs et appareils supportés

Le site est optimisé pour fonctionner avec :

  • Les versions récentes de Chrome, Firefox, Safari et Edge
  • Internet Explorer 11
  • Les appareils mobiles sous iOS et Android

Limites connues

Malgré nos efforts, certaines parties du site peuvent ne pas être entièrement accessibles :

  • Certains contenus tiers intégrés peuvent ne pas respecter les mêmes normes d'accessibilité
  • Certaines fonctionnalités avancées de la galerie peuvent être difficiles à utiliser avec certaines technologies d'assistance

Nous travaillons activement à résoudre ces problèmes.

Évaluation de l'accessibilité

L'accessibilité de notre site a été évaluée par :

  • Des tests automatisés avec des outils spécialisés
  • Des tests manuels avec différentes technologies d'assistance
  • Des tests utilisateurs impliquant des personnes en situation de handicap
